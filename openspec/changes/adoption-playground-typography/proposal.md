# Why
A personalização só alcança uma amostra, a troca de fontes não é evidente e laboratórios técnicos ocupam a navegação de adoção. O mantenedor pediu uma página completa interativa, três conjuntos tipográficos e ações verdes com texto claro.

# What Changes
- Playground de aplicação composto pelos componentes existentes, com modo, aparência e fontes independentes, configuração copiável e navegação funcional local.
- Três conjuntos tipográficos locais com papéis explícitos e opção legada para compatibilidade. Nova referência inicial Manrope / Source Sans 3 / Source Code Pro.
- Ações primárias verdes com texto branco e contraste medido em repouso/hover/active.
- Visão geral, personalização e tokens encaminham ao playground; revisão e fixtures técnicas saem do menu normal, preservando URLs de teste.

# Capabilities
## New Capabilities
- `refy-adoption-playground`: composição navegável, fontes demonstráveis, navegação editorial e ações primárias.
## Modified Capabilities
Nenhuma remoção de API pública.

# Impact
Storybook, página demonstrativa, presets de fontes exportados, arquivos/licenças de fonte, tokens gerados, documentação e testes. Sem migração de aplicações, publicação npm ou certificação assistiva.
